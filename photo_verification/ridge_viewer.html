📖 How to Use

  1. Enter Coordinates: Input latitude and longitude in decimal degrees format
  2. Select Direction: Choose the facing direction from the dropdown (1-360°, where 360° = North)
  3. Generate: Click the generate button to create a background image and analyze ridges
  4. View Results: The system will return the 100 closest visible ridge points along the horizon

🎯 Features:

  • Line-of-sight Analysis: Only shows ridges that are actually visible (not hidden behind other mountains)
  • Realistic Backgrounds: Generated from real elevation data
  • Detailed Statistics: Distance, elevation, and bearing for each ridge point
  • Multiple Formats: Command-line interface and web interface available
