## 📊 GPS Session Management & Persistence (v3.4.8)

### Session Persistence Behavior
- **Browser Refresh (F5)**: Same user + Same session (sessionStorage validation)
- **Browser Close/Reopen**: Same user + New session (localStorage device persistence)
- **Incognito Mode**: New user + New session (clean slate)
- **Manual New Session**: Same user + New session (button trigger)
- **24-Hour Expiry**: Same user + New session (automatic timeout)

### Session Validation System
- **Server-Side Validation**: All stored sessions validated with server before resuming
- **Auto-Recovery**: Invalid sessions automatically cleared and new ones created
- **Point Save Recovery**: Failed saves due to invalid sessions auto-retry with new session
- **Error Logging**: All session validation errors logged to server for debugging

### Global Session System
- **Format**: `session_NNNNNN_USERID_TIMESTAMP`
- **Example**: `session_000123_user_abc_1703875200`
- **Heartbeat**: 30-second client heartbeat to prevent timeouts
- **Auto-cleanup**: 30-minute inactivity timeout

### Session API Endpoints
```bash
# Start new session
curl -X POST http://localhost:8020/api/user/session/start \
  -H "Content-Type: application/json" \
  -d '{"userId": "test_user"}'

# Keep session alive
curl -X POST http://localhost:8020/api/user/session/heartbeat \
  -H "Content-Type: application/json" \
  -d '{"sessionId": "session_000123_user_abc_1703875200"}'

# Look up session
curl http://localhost:8020/api/session/lookup?number=123
```

## 🗺️ User-Adaptive Collection System

### Reactive Queue System
- **Purpose**: Automatically collect elevation data when users open GPS tracker
- **Trigger**: Monitors `/api/gps-queue` for new requests
- **Collection**: Concentric zones (10mi → 5mi → 1mi → 0.5mi → 0.1mi)
- **Database Naming**: `user_{userId}_{sessionId}_{latGrid}_{lonGrid}_radius{miles}.db`

### Collection Management
```bash
# Start reactive collection
cd user_adaptive_collection
node adaptive_collection_service.js start

# Check collection status
node adaptive_collection_service.js status

# List user databases
node adaptive_collection_service.js databases

# Test collection system
node adaptive_collection_service.js test
```
