# New Mexico Elevation Data Collection System - Mac Instructions
# Updated: June 28, 2025

## 🚀 Current System Status

### Core Services
- **Web Server**: Running on port 3000 (main elevation visualization)
- **Elevation API**: Located in `elevation/` directory with GPS tracking
- **Session Management**: Global session numbering with heartbeat system
- **Journey Dashboard**: Visual GPS session tracking with SVG maps
- **User-Adaptive Collection**: Reactive elevation data collection system

### Database Architecture
- **Main Database**: `mountains.db` (primary elevation data)
- **Grid Databases**: `grid_databases/` (location-specific elevation data)  
- **User Databases**: `user_adaptive_collection/` (user-specific GPS boundaries)
- **Session Tracking**: Global session counter with user metadata

## 🎯 Quick Start Guide

### 1. Start Core Services
```bash
# Start main web server
npm start

# Start elevation API (separate terminal)
cd elevation && php -S localhost:8020

# Start user-adaptive collection service
cd user_adaptive_collection && node adaptive_collection_service.js start
```

### 2. Access Web Interfaces
- **Main Elevation Map**: http://localhost:3000
- **GPS Live Tracking**: http://localhost:8020/gps_live.html
- **Journey Dashboard**: http://localhost:8020/gps_journey_dashboard.html
- **Elevation API**: http://localhost:8020/api/version

### 3. Test System Health
```bash

# Check GPS sessions
curl http://localhost:8020/api/sessions/recent
```

## 📊 GPS Session Management

### Global Session System
- **Format**: `session_NNNNNN_USERID_TIMESTAMP`
- **Example**: `session_000123_user_abc_1703875200`
- **Heartbeat**: 30-second client heartbeat to prevent timeouts
- **Auto-cleanup**: 30-minute inactivity timeout

### Session API Endpoints
```bash
# Start new session
curl -X POST http://localhost:8020/api/user/session/start \
  -H "Content-Type: application/json" \
  -d '{"userId": "test_user"}'

# Keep session alive
curl -X POST http://localhost:8020/api/user/session/heartbeat \
  -H "Content-Type: application/json" \
  -d '{"sessionId": "session_000123_user_abc_1703875200"}'

# Look up session
curl http://localhost:8020/api/session/lookup?number=123
```

## 🗺️ User-Adaptive Collection System

### Reactive Queue System
- **Purpose**: Automatically collect elevation data when users open GPS tracker
- **Trigger**: Monitors `/api/gps-queue` for new requests
- **Collection**: Concentric zones (10mi → 5mi → 1mi → 0.5mi → 0.1mi)
- **Database Naming**: `user_{userId}_{sessionId}_{latGrid}_{lonGrid}_radius{miles}.db`

### Collection Management
```bash
# Start reactive collection
cd user_adaptive_collection
node adaptive_collection_service.js start

# Check collection status
node adaptive_collection_service.js status

# List user databases
node adaptive_collection_service.js databases

# Test collection system
node adaptive_collection_service.js test
```

### Common Issues

2. **Database locks**: Restart services if SQLite locks occur
3. **FTP sync failures**: Check network connectivity and credentials
4. **Session timeouts**: Verify heartbeat system is active
